# Mini GTA 3D

Un petit jeu de type GTA en 3D, dans le navigateur, avec [Three.js](https://threejs.org/).

## Jouer

Ouvre `index.html` dans un navigateur récent (connexion internet requise pour charger Three.js depuis unpkg).
Tu peux aussi l'héberger tel quel sur GitHub Pages.

## Commandes

| Touche | Action |
| --- | --- |
| ZQSD / WASD / Flèches | Se déplacer / conduire |
| Maj | Courir |
| E | Entrer / sortir d'un véhicule (ou en voler un) |
| Espace | Sauter / frein à main |
| F | Frapper |
| C | Changer de caméra |

## Fonctionnalités

- Ville générée aléatoirement : immeubles, tours, parcs, routes et trottoirs
- Trafic automobile qui circule et tourne aux intersections
- Piétons qui se promènent sur les trottoirs
- Voitures garées ou en circulation à voler
- Billets à ramasser
- Niveau de recherche (1 à 5 étoiles) : la police te poursuit et peut t'arrêter
- Mini-carte avec la position de la police et des billets
